# Implementation and verification status

The repository now contains a runnable Community application, rather than only the PRD and reference design. The full thread goal remains active: fixture and local UI evidence does not prove live provider operation or public-beta readiness.

## Current evidence

- React/TypeScript production build passed.
- Four Vitest tests passed, covering safe preview defaults, action errors, and the ability to pause while synchronization is waiting.
- Nine Playwright workflows passed: edit/review/send simulation, persisted outcomes, later/dismiss, blocked senders, rule editing and deletion, consent requirements, history deletion, popover details/empty state, onboarding/reset, compact navigation, cached-message search, and pause/resume.
- Fifteen Rust tests passed: encrypted persistence and wrong-key rejection, persistent duplicate-send protection across reset/restart, transactional send/audit recovery and authentication preflight, OAuth callback state/duplicate-parameter validation, provider URL confinement, message normalization and Unicode/encoded headers, MIME wrapping, policy restrictions, sensitive subjects, trusted-sender matching, and conversation-context safety.
- Clippy passed with warnings denied.
- Both debug and optimized release `Tomo.app` bundles were built and launched. Native onboarding, the empty main window, and missing-client-ID error feedback were observed through the computer-use tools. The storage/tray deadlock found during this check was fixed and native rendering reverified. A processing pause survived quit/relaunch; resume kept auto-send off. The final ad hoc signed build is currently waiting for the user to approve macOS Keychain access to the encryption key created by the earlier development build. The computer-use tool blocks SecurityAgent, so this prompt cannot be handled by the agent.
- Browser screenshots of all four main screens and the two popover faces are saved in [`verification/`](verification/).

The native application has no connected accounts. Browser fixtures are explicitly labeled and are not used as production data.

## Scope preserved

Teams, local models, enterprise SSO/policies/control plane, managed deployment, cloud sync, mobile, Windows distribution, calendar automation, and browser-based communication adapters are explicitly later phases/out of the PRD's Community MVP.

## Live checks still required

Follow [`ACCOUNT_SETUP.md`](ACCOUNT_SETUP.md) with user-created Google/Microsoft registrations and an eligible AI account. Use disposable test messages and recipients controlled by the tester. Confirm unattended sync, structured classification, relevant thread context, edited delivery exactly once, restart recovery, consent withdrawal/pause, expired authorization, exhausted AI allowances, offline/backoff handling, disconnect deletion, native notifications, and uncertain-send reconciliation. Sign and notarize the public macOS binary using the maintainer's release identity before claiming beta readiness.
